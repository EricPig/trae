## 核心架构决策速查

### 决策 1：两层分离（准入层 vs 排序层）

> 基线清单 §8 项目级设计原则："当两个问题的最优解冲突时，不要在参数里找折中，而要在结构上分开它们。"

| 层 | 做什么 | 不做什么 | 模型 |
|----|--------|---------|------|
| **准入层** | 二维条件筛选（是否进候选池）| 不排序 | `locality_level × cuisine_evidence_level` + 差异化阈值 |
| **排序层** | 候选池内单标量排序 | 不准入判定 | `locality_score`（60/25/15 权重表）|

**为什么**：861 组单标量方案 Pareto 穷举 → 可行解 0。二维准入表是唯一解。

### 决策 2：安全硬过滤在召回层

> 过敏原违反率 = 0%（一票否决，架构级常量）

- 过滤位置：**候选集形成前**（召回层），而非排序降权
- 结果：AI 和排序层**看不到被过滤的条目**
- 过敏原数据缺失 = 诚实降级，AI **严禁推测**"可能不含"

### 决策 3：展示层四象限规则

> 基线清单 §1.5 裁决 1、§12.7「已准入不可折叠」

| | 本地性高（≥60） | 本地性低（<60）|
|--|--|--|
| **资料 🟢 高** | 最佳推荐位 | 排序降权 |
| **资料 🟡 中** | 重点扶持位 | 普通位 |
| **资料 🔴 低** | **禁降权、禁折叠、必优先** | 唯一允许折叠 |

**关键**：`evidence_strength` 只影响展示标签，**不参与降权**。

### 决策 4：AI 诚实优先

> 产品全案 §3.9 AI 态度 + N1–N7 不信任点

| AI 承诺 | 架构实现 |
|---------|---------|
| 不知道就说不知道 | Layer 4 诚实层 + 数据源缺失检测 |
| 不编造事实 | ACL（AI 不直连 DB）+ RAG 强制检索 + LLM 只做格式化 |
| 推荐必附依据 | RAG 证据链 + 五要素说明 |
| 明确能力边界 | 诚实档位声明 |
| 商业导流透明 | 推荐层与导流层物理隔离 + 明示佣金 |
